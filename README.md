# صدى المدينة

محاكاة عربية حيّة لمدينة صغيرة يعيش فيها 18 شخصًا. لكل شخص عمل وذاكرة وعلاقات وأهداف، ويتحرّك تلقائيًا مع نبض الخادم.

## ما تم بناؤه

- خريطة مرسومة مباشرة على Canvas بدل صورة ثابتة.
- شخصيات بشرية مرسومة ثنائية الأبعاد تتحرك بأذرع وأرجل وظلال وحركة مشي خفيفة.
- الحالة مشتركة بين زوار الخادم نفسه، ويحفظها Node.js في ملف JSON بعد كل نبضة.
- لا توجد دردشة مع الشخصيات، ولا مختبر ذكاء اصطناعي، ولا نموذج خارجي، ولا تحميل من Hugging Face.
- الخريطة تتكيف مع الهاتف، ويمكن الضغط على الشخصية لفتح ملفها.

## التشغيل

```bash
npm start
# افتح http://localhost:3000
```

يتطلب Node.js 20 أو أحدث. لا يحتاج المشروع إلى خدمة ذكاء اصطناعي أو مفتاح API.

## الحفظ والاستضافة

الخادم الدائم يحفظ المدينة في `data/world.json`. شغّله على منصة تبقي عملية Node قيد التشغيل وتوفر قرصًا دائمًا أو قاعدة بيانات. إذا أوقف المضيف العملية أو حذف القرص، فلن يكون هناك حفظ مضمون؛ فعّل نسخًا احتياطية خارجية.

للتجربة المجانية السهلة، Render Free مناسب للمعاينة لكنه ينام بعد الخمول وتخزينه المحلي غير مناسب لعالم دائم. للحالة الدائمة المجانية، Oracle Cloud Always Free VM أقرب إلى المطلوب، لكنه يحتاج حسابًا وتحققًا وقد تتوفر الموارد بحسب المنطقة. عند استخدام خادم مجاني، شغّل systemd أو Docker مع نسخة احتياطية.
