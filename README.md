# Echo City — New Life Simulation

محاكاة حياة تفاعلية أصلية لمدينة صغيرة تبدأ موسمًا جديدًا مع 18 مواطنًا مستقلًا. الواجهة مناسبة للهاتف وسطح المكتب، والخريطة مرسومة برمجيًا، مع أحداث يومية وعلاقات واستطلاع وسجل حياة وقناة محادثة مع الشخصيات.

## التشغيل

يتطلب المشروع Node.js 18 أو أحدث لتشغيل محاكاة المدينة:

```bash
npm start
# افتح http://localhost:3000
```

## الذكاء الاصطناعي والبث الحي

المحادثة لا تستخدم خادم AI ولا أي مفتاح. يستخدم الموقع **Transformers.js** داخل المتصفح لتحميل وتشغيل نموذج ONNX المفتوح **onnx-community/Qwen2.5-0.5B-Instruct** من Hugging Face عبر روابط عامة. النموذج يعمل على جهاز كل زائر؛ لذلك ردود المحادثة مستقلة على كل جهاز، وليست محادثة AI مركزية مشتركة، ولا توجد بيانات سرية في المستودع.

يُحمّل النموذج عند أول فتح لقناة خاصة، ويُخزّن في ذاكرة التخزين المؤقت للمتصفح بعد ذلك. أول تشغيل قد يحتاج وقتًا ومساحة تنزيل كبيرة نسبيًا، وتختلف السرعة حسب الهاتف أو الكمبيوتر. استخدمت نسخة Q4 لتقليل الحجم، ويمكن لـ Transformers.js استخدام WebAssembly في المتصفحات التي لا تدعم WebGPU.

حالة المدينة والأحداث مشتركة بين جميع الزوار المتصلين **بنفس عملية Node.js**: الخادم يحرّك المحاكاة مرة كل 7 ثوانٍ، والمتصفحات تقرأ الحالة المشتركة عبر `/api/state`. لا ترسل المتصفحات نبضات تغيّر حالة المدينة، لذا لا تتسارع المحاكاة بزيادة عدد الزوار. يجب تشغيل نسخة خادم واحدة للحفاظ على حالة موحّدة؛ التوسّع على عدة عمليات أو خوادم يحتاج مخزن حالة مشتركًا غير مضمّن هنا.

المراجع الرسمية: [نموذج Qwen2.5 ONNX على Hugging Face](https://huggingface.co/onnx-community/Qwen2.5-0.5B-Instruct)، [Transformers.js](https://huggingface.co/docs/transformers.js/en/index)، و[بطاقة نموذج Qwen الأساسي وترخيص Apache-2.0](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct).

## الأصالة والترخيص

الكود والواجهة والخريطة والرسومات المضمنة في هذا المشروع مولدة لهذا المشروع وليست نسخًا من ملفات المنصة المرجعية. لا توجد مفاتيح أو بيانات سرية مطلوبة. نموذج الذكاء الاصطناعي نفسه مفتوح المصدر بحسب ترخيصه الرسمي؛ راجع بطاقة النموذج وشروط Hugging Face قبل الاستخدام التجاري.

## التحقق

تم اختبار ملفات JavaScript، الصفحة، CSS، فتح ملف المواطن في المتصفح، واجهات الصحة وحالة المحاكاة وبيانات نموذج AI. نموذج ONNX متاح للعامة على Hugging Face، ومكتبة Transformers.js تشغّل النماذج داخل المتصفح. ترخيص النموذج الأساس Qwen2.5-0.5B-Instruct هو Apache-2.0؛ راجع بطاقة النموذج ومصدر ONNX قبل الاستخدام التجاري أو إعادة التوزيع.
