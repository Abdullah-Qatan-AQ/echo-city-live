# صدى المدينة — عالمٌ يتغيّر

محاكاة عربية أصلية لمدينة صغيرة يعيش فيها 18 شخصًا لكلٍ منهم عملٌ وذاكرةٌ وروابط وأمنيات. صُممت الواجهة من جديد باتجاه RTL، وخريطة مرسومة خصيصًا لهذا المشروع، وأقسام متجاوبة للهاتف وسطح المكتب. لا تستنسخ بنية الموقع المرجعي أو رسوماته.

## التشغيل محليًا

يتطلب Node.js 20 أو أحدث، ولا يحتاج إلى حزم npm خارجية:

```bash
npm start
# ثم افتح http://localhost:3000
```

## العربية والرسم

- الواجهة والبيانات والأحداث والصحيفة ورسائل الشخصية مكتوبة بالعربية.
- اتجاه RTL وتخطيطات الهاتف مدمجان في الصفحة، لا مجرد ترجمة للأزرار.
- رسم الخريطة `public/assets/echo-city-map.webp` أصلي لهذا المشروع؛ تظهر فوقه علامات المواطنين التفاعلية.
- يمكن اختيار شخصية من العلامة على الخريطة أو من قائمة السكان.

## الذكاء الاصطناعي

المحادثة تستخدم **Transformers.js** داخل متصفح الزائر لتحميل أوزان **onnx-community/Qwen2.5-0.5B-Instruct** من Hugging Face وتشغيلها على جهازه. لا يوجد مفتاح أو طلب AI خلفي. هذه محادثات مستقلة في كل متصفح وليست بث محادثة مركزيًا موحّدًا. التنزيل الأول كبير — ملف Q4 الذي تحققنا منه يقارب 786 ميغابايت — وتتوقف ميزة الحوار إذا لم يتوفر اتصال بالإنترنت أو ذاكرة كافية.

بطاقة مستودع ONNX متاحة للعامة وموسومة للتوافق مع Transformers.js. بطاقة النموذج الأساس Qwen2.5-0.5B-Instruct تعلن ترخيص Apache-2.0؛ مستودع ONNX لا يعرض تصريح ترخيص مستقلًا في بياناته التي راجعناها. قبل الاستخدام التجاري أو إعادة التوزيع، راجع شروط المستودعين والتزامات كل مكوّن: [أوزان ONNX](https://huggingface.co/onnx-community/Qwen2.5-0.5B-Instruct)، [النموذج الأساس وترخيصه](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct)، [Transformers.js](https://huggingface.co/docs/transformers.js/en/index).

## حالة المدينة المشتركة والحفظ

جميع المتصفحات المتصلة **بعملية الخادم نفسها** تقرأ حالة المدينة ذاتها من `/api/state`. الخادم وحده يحرّك الوقت مرة كل سبع ثوانٍ؛ لا يستطيع كل زائر تسريع المحاكاة بإرسال نبضات إضافية. أُضيفت كتابة ذرية للحالة إلى ملف JSON بعد كل نبضة وإعادة تحميلها عند بدء الخدمة، إضافةً إلى إغلاق نظيف ونقطة فحص `/health`.

إعادة ضبط العالم معطلة افتراضيًا لأنها تؤثر في الجميع. لا تفعّل `ALLOW_PUBLIC_RESET=true` إلا إذا كان المضيف خاصًا وتقبل أن يستطيع كل من يصل إليه إعادة ضبط المدينة.

تشغّل النسخة الافتراضية خادم Node واحدًا. لا تشغّل نسخًا متعددة من دون إضافة قاعدة بيانات/مخزن حالة مركزي وتنسيق أقفال؛ كما أن ملف الحالة المحلي ليس نسخة احتياطية خارج الخادم.

## التوافر طويل الأمد

لا يمكن ضمان بقاء أي موقع أو خادم أو نطاق أو مزود نموذج متصلًا بلا انقطاع 100 سنة؛ الأجهزة والمزودون والشبكات والبرمجيات تحتاج صيانة وتتغير بمرور الزمن. هذا المستودع **ليس استضافة دائمة**، ومعاينة Manus المؤقتة ليست وعدًا بالتشغيل الدائم.

لتقليل احتمال التوقف والاستعادة بسرعة، يتضمن المستودع أمثلة تشغيل جاهزة:

- `deploy/echo-city.service`: خدمة systemd مع إعادة تشغيل آلية عند تعطل Node.
- `deploy/echo-city-backup.service` و`deploy/echo-city-backup.timer`: نسخ يومي لملف الحالة.
- `scripts/backup-state.sh`: إنشاء نسخة مؤرخة من الحالة.
- `Dockerfile` و`compose.yaml`: تشغيل حاوية مع مجلد بيانات دائم وإعادة تشغيل عند الخروج.

للاستخدام العام الطويل الأمد، شغّل المشروع على مزود استضافة دائم يدعم مراقبة الصحة وإعادة التشغيل، واضبط نسخًا احتياطية **خارج المضيف** واختبارات استعادة وتنبيهات بشرية، وحدّث نظام التشغيل وNode والتبعيات بانتظام. النسخ الاحتياطي المحلي وحده لا يحمي من تلف القرص أو فقدان الخادم. لتحقيق توافر أعلى من خادم واحد، يلزم تصميم موزع بقاعدة بيانات مشتركة وموازن حمل ومراقبة؛ وهذا غير مهيأ تلقائيًا هنا.

لتشغيل systemd، انسخ ملفات الوحدة إلى `/etc/systemd/system/` بعد تعديل مسارات `/opt/echo-city` واسم المستخدم وفق خادمك، ثم نفّذ:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now echo-city.service
sudo systemctl enable --now echo-city-backup.timer
sudo systemctl status echo-city.service
```

يُخزّن الملف الافتراضي الحالة في `data/world.json` (مستبعد من Git). غيّر المسار عبر المتغير `ECHO_STATE_FILE`، واضبط `PORT` إذا لزم.
